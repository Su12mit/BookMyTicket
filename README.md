##### 🎟️ BookMyTicket Website



A dynamic and user-friendly web application for booking movie tickets online. The system allows users to browse the latest movies, view theater details, select their preferred seats, and securely purchase tickets.



###### ✨ Key Features



**Browse Movies:** 🎬 View a catalog of the latest movies with details on categories and showtimes.



**Theater Selection:** 📍 Choose from a list of available theaters and locations.



**Seat \& Class Selection:** 💺 Select specific seats and choose a class (e.g., Economy, Gold, VIP) for a tailored booking experience.



**Secure Payments:** 💳 Integrated payment gateway to handle online transactions safely.



**Intuitive Interface:** 💻 Built with Bootstrap to ensure a responsive and easy-to-navigate design.





###### 🛠️ Technologies Used



**Backend:** PHP



**Frontend:** HTML5, CSS3, Bootstrap



**Database:** MySQL



**Server:** XAMPP
